# New RubyGems

Hourly lists of gems newly published to
[RubyGems](https://rubygems.org/), taken from the
[latest activity API](https://rubygems.org/gems/rubygems-api-key).
A GitHub Actions workflow runs every hour, fetches the gems created since
the previous list and commits one CSV per run to [`data/`](data/), e.g.
[`data/new-gems-<timestamp>.csv`](data/).

Read the latest list below.
